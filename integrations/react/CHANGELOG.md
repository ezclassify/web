# Changelog

All notable changes to `@ezclassify/react` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## 1.0.0

The first public release. The React binding of the EzClassify forms library.
You name your engine once and the integration mounts the `@ezclassify/ui`
runtime on native form inputs. It never builds an engine itself.
